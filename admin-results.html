Results & Trophy Tool

New to this tool? Here's the order to work in

  1. Add your entrants — upload the CSV or add people one at a time as late entries come in.
  2. Enter each class result as judging finishes, using the IDs from the entry cards. Joint placements just get more than one ID.
  3. Leave the trophies to work themselves out — every cup updates the moment you save a result. The Handicraft cups will ask you a quick question if they need to know someone's gender to decide a winner.
  4. At 4.30pm, hit "Print prize-giving sheet" for a single page listing all 41 trophies and their winners.

Everything is saved automatically in this browser as you go — see "Backup / sharing" below if you need to hand this over to someone else or use a different device.

1 Entrants

Upload entrants CSV

Upload the "Category Matrix" spreadsheet exported from the entries system (Name in the first column, one column per class after it). Each entrant's ID matches their actual row number in that spreadsheet (row 2 = ID 2, and so on — ID 1 is never used, since that's the header row). The class columns are also totalled up — see "Print entries-per-category sheet" below. Meant as a single import once entries close. Anyone added after that (e.g. on the day) should go through "Add / edit an entrant manually" below instead.


Add / edit an entrant manually


2 Enter a class result

If a place is shared, enter more than one ID separated by commas — e.g. 12,18 for joint 1st. Each ID listed for a place gets the full points for that place.


3 Class results record

Each class below has its own "Print" button for a single filled-in class sheet (matching your paper record sheets). Sheets print two-per-row to fit more on a page, flowing naturally onto further pages as needed.

4 Overall entrant leaderboard

This is every entrant's total points added up across every class — useful as a quick overview, but the actual trophies below are each based on their own specific set of classes, per the show rules.

5 Trophies

Computed automatically from the class results above, following Show Rule 8's points system (1st=5, 2nd=3, 3rd=2, HC=1) and tie-break (most 1st places, then most 2nd places). Trophies marked Judged aren't decided by points — they're the judge's choice of best exhibit, so just type the winner in in the box provided for your records and the prize-giving sheet. The two Handicraft cups are restricted by gender — if the top scorer's gender isn't known yet, you'll be asked right there, one person at a time, only when it actually affects the result.

R.H.S. Banksian Medal — once every 3 years (Show Rule 8)

"Competitors can only win this Medal once every three years." Once all of Sections A–D are entered, the Medal's row above will ask you to confirm whether its current leader has won it within the last 2 shows (i.e. too recently to be eligible again this year). Answer "Yes" and it moves on to the next person down; answer "No" and they're confirmed as the winner.

Prize-giving sheet

Prints (or saves as PDF) a single sheet listing all 41 trophies in order, with the current winner for each — ready to read out at 4.30pm.

Trophy winners list

A simpler version matching your existing "Show Challenge Cups Winners" sheet — just cup number, trophy title, and winner, nothing else.
